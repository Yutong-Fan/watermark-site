# 水印配色助手 · 官网

给姐姐用的水印配色工具。选一张图，分析主色，给出五款配色方案，点击复制色值。图片只在本地处理。

## 设计

- 低饱和蓝灰配色（`#5b8abf`），克制圆角（6–14px），零分割线，阴影卡片分隔
- 全站系统字体栈，字号间距全 `clamp()` 自适应
- 跟随系统深浅色，支持手动切换（记忆选择）
- 色卡五款方案：同色系、互补色、邻近色、中性色、莫兰迪
- 下载按钮点击后弹出浮窗提示「想我了吗。」，5 秒自动消失，可点击提前关闭（最少 1.5 秒）
- 响应式：手机汉堡菜单 / 平板多列 / 桌面双栏 Hero + 三列网格

## 动效

- 载入序列：导航下滑 → 标题上浮 → 按钮上浮 → 色卡依次着色
- 滚动显现：fade-up + 卡片级联延迟
- 色卡分析：扫描光带 + 脉冲点 → 淡出 → "点击复制"浮现
- 微交互：按钮 hover 上移、色卡弹起放大、主题切换旋转、时间线圆点变色
- 尊重 `prefers-reduced-motion`

## 文件结构

```
├── index.html            主页面
├── css/
│   ├── tokens.css        设计令牌（颜色、字体、间距、圆角）
│   ├── base.css          reset、tap 高亮清除、防深色反转
│   ├── components.css    导航、按钮、色卡、卡片、时间线、下载、toast
│   ├── layout.css        容器、Hero、区块渐变过渡、断点
│   └── motion.css        动效系统（载入、滚动、微交互）
├── js/main.js            汉堡菜单、深浅切换、色卡复制、下载 toast
├── assets/icon.png       应用图标
└── apk/                  安装包
```

## 部署

纯静态页面，部署到任意静态托管（GitHub Pages、Netlify 等）。将 APK 放入 `apk/` 目录即可。
