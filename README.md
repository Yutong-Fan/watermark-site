# 水印配色助手 · 官网

给原创圈创作者的水印配色工具官网。选一张图，分析主色，给出五款水印配色，点一下复制色值。图片只在本地处理。

## 页面

- 苹果官网风格，与 App（结绳 `水印配色_主题`）配色一致：浅灰底白卡 + 苹果蓝 `#0071E3`，深色纯黑底 + 亮蓝 `#2997FF`
- 全站无衬线字体，胶囊按钮（主按钮苹果蓝渐变、次要按钮浅蓝填充）
- 跟随系统深浅色，支持手动切换（记忆选择）
- 示例色卡五款方案名称与 App 完全一致：同色系协调、互补色对比、邻近色柔和、中性色百搭、莫兰迪质感
- 动效编排（`css/motion.css`，全部尊重减弱动效设置）：
  - 载入序列：导航滑入 → hero 文案逐行浮起 → 强调词下划线绘制
  - 分析时刻：色卡浮入 + 扫描光带 + "正在分析主色"脉冲点 → 五块色卡依次着色浮现 → "点击色卡复制"提示浮现
  - 滚动显现：模糊淡入 + 条目级联延迟；hero 柔光呼吸；按钮/色卡/获取卡微交互
- 色卡点击复制（含剪贴板降级方案），复制后色块显示 ✓ 弹出反馈

## 文件结构

```
├── index.html            主页面
├── css/
│   ├── tokens.css        设计令牌（苹果风颜色、字体、深浅色）
│   ├── base.css          reset、排版、焦点
│   ├── components.css    导航、按钮、色卡、清单、步骤
│   ├── layout.css        布局与响应式
│   └── motion.css        动效层（载入编排、滚动显现、微交互）
├── js/main.js            滚动显现、色卡复制、深浅切换
├── assets/icon.png       应用图标
└── apk/                  安装包（可放 APK，页面下载按钮指向这里）
```

## 部署

纯静态页面，直接部署任意静态托管（GitHub Pages、Netlify 等）。将 APK 放入 `apk/` 目录即可启用下载按钮。
